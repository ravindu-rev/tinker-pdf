dictionary.bin is the DICT array of RFC 7932 (Brotli Compressed Data Format),
Appendix A, "Static Dictionary Data" -- 122 784 bytes whose CRC-32 the RFC
publishes as 0x5136cb04.

RFC 7932 is an IETF-stream document ("Internet Engineering Task Force (IETF)",
approved for publication by the IESG), so section 4 of the IETF Trust's Legal
Provisions Relating to IETF Documents applies to it in full. Appendix A is a
Code Component: TLP 4.a defines Code Components by reference to the Trust's
published list, and "tables of values" is an entry on that list (Code
Components 3.0, 23 April 2009). RFC 7932's own Copyright Notice says so
directly:

The Legal Provisions in effect on that date are TLP 5.0 (effective 25 March
2015). Its section 4.c carries the licence text below and states that it "is
intended to be compatible with the Revised BSD License template published at
https://opensource.org/licenses/BSD-3-Clause" -- three clauses, not two, so the
SPDX identifier is BSD-3-Clause. (TLP 5.0 renamed what RFC 7932's boilerplate
calls the "Simplified BSD License" to the "Revised BSD License"; the text is
unchanged and is reproduced here in full, as TLP 4.e option (1) permits.)

The same licence covers the other tables this crate transcribed out of the
same RFC and keeps in `src/brotli.rs` rather than here, because they are small
enough to read: Appendix B's 121 word transformations, section 7.1's Lut0,
Lut1 and Lut2 context tables, and the length and count tables of sections 5
and 6. Each carries the RFC's own published CRC-32 as a unit test.
