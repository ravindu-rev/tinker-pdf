# Tier 0 — measure what is not measured

[The roadmap](../ROADMAP.md) says how a step is worked and what comes next.

Each row here is an axis the field judges an engine on and this repository
has no number for, so a claim about it would be the kind of claim ruling 13
exists to prevent. The rows build the instrument tier P is held to, and the
censuses no corpus run has fed.

## MS-01 — Counted-work guards on every pull request and every target

**Counted-work guards on every pull request and every target.** A first-party `Work` tally — plain counters, no clock, no `unsafe` — threaded through the operation contexts the work budgets already use, and surfaced as an opt-in statistics value on the facade (`RenderOptions::stats` → `Bitmap::stats()`, the same for text, save, merge and decode) so the guards test the public surface (ruling 11)

**Exit criterion.** `cargo test` runs the guard suite on Linux and Windows (CI runs it on every pull request) and under `--target wasm32-wasip1` locally — A1 `page(i)` visits ≤ depth × fan-out nodes and every page of a generated 10 000-page document ≤ 3 × 10 000 in total; A2 work(4 000 pages) ≤ 4.4 × work(1 000) for text, render-all at 36 dpi, rewrite, rotate, merge, split, subset, redaction and validation; A3 font dictionaries resolved per page ≤ distinct `/Font` entries used; A4 glyph masks rasterised ≤ distinct (font, glyph, scale, phase) keys, hit ratio ≥ 98 % on a 5 600-glyph page; A5 inflate calls per stream ≤ 1 per operation; A6 merge deduplication decompresses nothing unless encoded length and encoded hash collide; A7 IDCT output ≤ 4 × drawn pixels for a quarter-scale draw, JPX levels decoded ≤ levels needed; A8 whole-image scratch on the PNG path ≤ 1 × the image; A9 band- and page-parallel renders byte-identical to serial at 2, 3, 4 and 7 threads; A10 allocations O(1) per page. Each guard lands with its P row

## MS-02 — A paired base-versus-head wall-clock gate, run locally

**A paired base-versus-head wall-clock gate, run locally.** Base and head built on one machine, the suite run interleaved ten rounds, each operation judged by the median paired ratio and a sign test (fails when the ratio exceeds 1 + band and at least 8 of 10 pairs are slower)

**Exit criterion.** `cargo xtask bench-check --paired BASE HEAD` reads criterion's `estimates.json`/`sample.json` for both (no second timing), with unit tests including an injected 10 % slowdown that it catches and an A/A pair it passes; a local run builds base and head on one machine and runs it, recorded in the row it closes; each operation's band = worst A/A paired spread over 15 local runs × 1.5, rounded up to 5 %, floor 5 %, recorded in `verification.md`; the same run builds the MS-04 suite a second time against `61adcde`, the planning baseline, and holds each operation's paired ratio to its committed factor floor, its calibrated targets against the calibration operation run beside them, and its relations (tier P's Gate column)
